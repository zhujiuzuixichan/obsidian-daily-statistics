# Obsidian Daily Statistics

统计每日书写的字数，并展示在日历中。

![alt text](image.png)

## 介绍

这是一款每日字数统计插件，通过日历直观展示你在 Obsidian 库中每天写了多少字。你可以在侧边栏打开日历面板，实时查看当日字数，并为每周设置目标、追踪完成进度。

本仓库基于 [yefengr/obsidian-daily-statistics](https://github.com/yefengr/obsidian-daily-statistics) 二次开发，在原有功能基础上新增了防复制粘贴、防剪切、统计面板、文件明细等实用能力。

## 功能

### 基础功能

- 统计每日字数（字符数或单词数），展示在日历中
- 指定需要统计的文件夹（支持多个目录，逗号分隔）
- 设置每周目标，未设置时默认沿用上一周的目标
- 开启计划后，日历下方显示计划进度，达标当天变为绿色
- 鼠标双击日期，手动修改当日字数
- 手动设置一周的开始时间
- 多语言：中文、英文
- 支持移动端

### 新增功能（v1.7.0 / v1.8.0 / v1.9.0 / v1.10.0 / v1.11.0）

- **防复制粘贴**：单次新增超过阈值字数时，视为一次复制/粘贴，不计入当日统计。可在设置中开启/关闭，并自定义阈值（默认 1000 字，设为 0 表示不限制）。
- **防剪切**：单次减少超过阈值字数时，视为一次剪切（如将内容移动到新文档），原文档字数以剪切后为准，不计入当日减少；当检测到「剪切字数 = 粘贴字数」时按移动处理、不做统计。可在设置中开启/关闭，并自定义阈值（默认 1000 字，设为 0 表示不限制）。
- **排除目录勾选器**：在设置中以勾选库中子文件夹的方式排除目录，无需手动输入路径。
- **统计面板**：日历下方显示「今日 / 本周 / 本月 / 本年」的字数汇总。
- **日均输入**：统计面板新增「本周日均 / 本月日均 / 本年日均」，即该周期累计字数 ÷ 该周期已进行的天数（含今天）。
- **输入峰值**：统计面板新增「单日 / 单周 / 单月 / 单年」输入峰值，并标注峰值对应的日期（单周按周一起始计算）。
- **自定义时间范围统计**：任选起止日期，统计区间内累计字数。
- **文件明细**：查看某一天的字数由哪些文件贡献，按字数排序，点击文件名可直接打开对应文件。

## 安装

### 方式一：BRAT 安装（推荐）

1. 在社区插件中安装 [BRAT](https://github.com/TfTHacker/obsidian42-brat)。
2. 打开 BRAT 设置，点击「Add Beta plugin」。
3. 输入仓库地址：`zhujiuzuixichan/obsidian-daily-statistics`。
4. 在社区插件的「已安装插件」中启用「Daily Statistics」。

### 方式二：手动安装

1. 在 [Releases](https://github.com/zhujiuzuixichan/obsidian-daily-statistics/releases) 页面下载最新版本的 `main.js`、`manifest.json`、`styles.css`。
2. 在你的库中创建目录 `.obsidian/plugins/daily-statistics/`。
3. 将下载的三个文件放入该目录。
4. 在 Obsidian 中启用「Daily Statistics」。

## 使用说明

- **打开日历面板**：安装启用后会自动在侧边栏打开；也可通过命令面板执行「打开日历面板」。
- **查看统计汇总**：日历下方统计面板显示「今日 / 本周 / 本月 / 本年」累计字数、日均输入，以及单日 / 单周 / 单月 / 单年输入峰值。
- **修改当日字数**：在日历上双击某个日期，输入字数即可手动修正。
- **查看文件明细**：日历下方「文件明细」区默认展开，显示当天各文件的贡献字数；可通过日期选择器查看历史某一天的明细。
- **自定义范围统计**：在统计面板底部选择起止日期，点击「统计」查看区间累计字数。

## 配置说明

| 设置项 | 说明 |
| --- | --- |
| 统计数据保存地址 | 自定义统计数据的保存位置，留空则保存在插件默认目录 |
| 统计目录 | 需要统计的目录，多个目录用英文逗号分隔，留空则统计全库 |
| 排除目录 | 勾选需要排除的子文件夹，不勾选则统计全库 |
| 统计单词 | 统计单词数而非字符数（适合英文写作） |
| 防复制粘贴 | 开启后单次新增超过阈值视为粘贴，不计入统计 |
| 粘贴阈值 | 单次新增超过该字数即视为粘贴；设为 0 表示不限制 |
| 防剪切 | 开启后单次减少超过阈值视为剪切，原文档以剪切后字数为准 |
| 剪切阈值 | 单次减少超过该字数即视为剪切；设为 0 表示不限制 |
| 开启计划 | 日历下方显示计划进度 |
| 一周开始时间 | 设置每周的起始日 |
